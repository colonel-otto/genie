# genie-json

Read and write the JSON data tables Age of Empires II: Definitive Edition loads from
`resources/_common/dat`: `linkedTechs.json`, `dropsites.json`, `futuravailableunits.json` (and
the Paphos variant), `maps.json`, `buttons.json`. Every key the files hold is typed; an unknown key
is an error, so a new game version's additions show up instead of vanishing.
